Plataforma digital orientada a la exploración, clasificación y selección de obras literarias y académicas.

---

##  Descripción del Sistema

La interfaz de **Biblioteca Horizonte** proporciona un entorno estructurado para la consulta de catálogos mediante navegación por categorías, autenticación básica de usuarios y gestión interactiva de títulos seleccionados en tiempo real.

---

##  Funcionalidades Implementadas

* **Módulo de Autenticación:** Formulario de acceso rápido mediante correo electrónico.
* **Métricas en Tiempo Real:** Contador dinámico de ejemplares seleccionados por el usuario.
* **Clasificación por Categorías:** Sistema de filtrado temático compuesto por:
  * Novelas
  * Ciencia
  * Historia
  * Tecnología
  * Arte
  * Infantil
* **Sección Informativa (Hero):** Presentación institucional del repositorio digital.
* **Catálogo de Recomendaciones:** Listado funcional con ficha técnica (título, autor), enlace de consulta detallada y selector individual de ejemplares (*Cien años de soledad*, *Sapiens*, *El principito*).

##  Instalación y Uso Local

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/biblioteca-horizonte.git
   ```
2. **Navega al directorio del proyecto:**
   ```bash
   cd biblioteca-horizonte
   ```
3. **Ejecuta el proyecto:**
   Abre el archivo `index.html` directamente en tu navegador web de preferencia.
