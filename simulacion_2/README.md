Biblioteca Horizonte — Documentación del Proyecto Web
Este repositorio contiene la arquitectura e implementación del sitio web para Biblioteca Horizonte, una plataforma digital orientada a la exploración, clasificación y selección de obras literarias y académicas.

Descripción del Sistema
La interfaz proporciona un entorno estructurado para la consulta de catálogos mediante navegación por categorías, autenticación de usuarios y gestión interactiva de títulos seleccionados.

Funcionalidades Implementadas
Módulo de Autenticación: Formulario de acceso rápido mediante correo electrónico.

Métricas en Tiempo Real: Contador dinámico de ejemplares seleccionados por el usuario.

Clasificación por Categorías: Sistema de filtrado temático compuesto por:

Novelas

Ciencia

Historia

Tecnología

Arte

Infantil

Sección Informativa (Hero): Presentación institucional del repositorio digital.

Catálogo de Recomendaciones: Listado funcional con ficha técnica (título, autor), enlace de consulta detallada y selector individual de ejemplares (Cien años de soledad, Sapiens, El principito).

Tecnologías Utilizadas
HTML5: Marcado semántico y estructura del documento.

CSS3: Hojas de estilo para la maquetación, tipografía y distribución visual.

JavaScript: Control de eventos, gestión de selección e interactividad con el cliente.
